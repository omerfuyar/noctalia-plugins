# Noctalia Plugins

Plugins for [Noctalia](https://noctalia.dev) v5. Many bring features of Omarchy plugins to Noctalia.

## Install

Add this repository as a plugin source:

```bash
noctalia msg plugins source add omerfuyar git https://github.com/omerfuyar/noctalia-plugins
```

Then enable plugins in Noctalia's settings, under Plugins.

What each plugin does is in [OVERVIEW.md](OVERVIEW.md).
